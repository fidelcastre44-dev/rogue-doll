# Rogue Doll — proto combat v0.11 (24/10/2026)

- Ragdoll visuel (méthode officielle Godot + réglages de la démo « Ragdoll Physics ») : en l'air le corps ballotte autour de la trajectoire du jongle, au sol il tombe librement, puis se relève depuis sa pose (dos / ventre). Aussi sur le héros renversé. Menu Start : on / off.
- Aide « possible maintenant » en bas à droite : les boutons utiles à cet instant (ex. après un lanceur qui touche : A = saut de poursuite puis X X X en l'air), grisés avec le nombre d'images tant que la fenêtre n'est pas ouverte. Indice de situation en haut. F1 = liste complète.
- Windows : RogueDollCombat-v0.11-windows.zip ; Mac : RogueDollCombat-v0.11-mac.zip.
