# Rogue Doll v0.2 — Éditeur d'animation (F3)

- F3 ouvre l'éditeur d'animation (séparé du labo : F2 = labo, Échap = jeu)
- Choisir un coup (mêmes noms que le labo), attraper un membre à la souris pour le tourner, curseurs X / Y / Z pour le réglage fin
- Vue de profil par défaut, vue 3D libre avec Tab
- Frise des poses clés : ajouter, supprimer, glisser une clé pour changer le rythme ; courbes entre les clés
- Lecture en boucle, ralenti, image par image, pelure d'oignon, copier / coller, miroir gauche-droite, annuler / rétablir
- Un sbire en face et la zone de frappe pour juger l'impact
- Versions nommées par coup ; la version cochée est celle que le jeu utilise, tout de suite (F2 pour l'essayer)
- « Tout exporter » : un seul fichier sur le Bureau, à déposer sur le site, onglet Animations
