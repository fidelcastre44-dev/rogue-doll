# Proto combat v0.112 (24/10/2026)

- Caméra moins plongeante (40°) ; menu Start : rotation 360°, inclinaison, zoom (gardés).
- Chope tenue jusqu'à 3 s : Y = l'éclater au sol (il rebondit, jonglable), X = frapper, RB = lancer, B = lâcher ; sinon il se dégage.
- Mur d'armes (situation « armes ») : épée, katana, hache, batte. RB = prendre / raccrocher. Coups propres à chaque arme, zone de frappe sur la lame.
- Rebords (zone « parcours ») : enjamber, s'agripper, se déplacer le long, se hisser, lâcher (d'après Climbing Physics Prototype, MIT).
- Course au mur (couloir, zigzag, mur long) : sauter le long d'un mur = courir dessus ; A = saut vers le mur d'en face (d'après godot-wall-running, MIT).
