# Rogue Doll v0.22 (24/10)

Le héros a un vrai modèle 3D.

- Le héros n'est plus en cubes : modèle 3D homme ou femme, qui joue exactement les mêmes animations (coups, déplacements, plongeon pantin).
- F4 (partout) : homme → femme → cubes. Le choix est gardé d'une partie à l'autre.
- Rien ne change dans le jeu : mêmes coups, mêmes zones de frappe, mêmes retouches de l'éditeur d'animation.
- L'éditeur d'animation (F3) reste en cubes pour attraper les membres facilement.
