# Rogue Doll — proto combat v0.1 (24/10/2026)

Version à part du jeu principal : seulement le terrain d'essai, avec un déplacement / combat refaits de zéro (pas de ragdoll).
- Vraies animations sur le modèle Superhero (Quaternius UAL 1 & 2, CC0, même squelette) + captures CMU (coups de pied, uppercut, crochet, garde).
- Coups réglés en images comme un jeu de combat (armé / actif / récupération), tampon d'entrées 150 ms, annulations, figé à l'impact, secousse caméra, étincelles, traînées, sons.
- X : jab ▸ direct ▸ crochet ▸ coup retourné ; Y dans l'enchaînement : uppercut lanceur ▸ A saut de poursuite ▸ combo aérien.
- Y : coup de pied poussé (brise la garde) ▸ gros crochet (écrasé contre le mur) ; Y maintenu : chargé.
- Roulade invincible ▸ X / Y ; esquive parfaite (ralenti) ; garde / parade ▸ riposte ; chope et lancer (bowling) ; dash et piqué aériens.
- Mannequins passifs / en garde / qui attaquent (2 à la fois) ; aide à la visée réglable (menu Start).
- Windows : RogueDollCombat-v0.1-windows.zip ; Mac : RogueDollCombat-v0.1-mac.zip (clic droit → Ouvrir la 1re fois).
- Code : dépôt rogue-doll-code, dossier proto_combat/.
